# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories
for this repository. Do not open a public issue containing tenant identifiers,
tokens, deployment output, or other sensitive telemetry.

Include the affected deployment mode, reproducible behavior, expected trust
boundary, and suggested mitigation when available. Treat exposed credentials,
federated identity configuration, or Function keys as compromised and rotate
or revoke them before reporting.

This project is maintained on a best-effort basis by a single maintainer.
